# AI PR Advisor

A portable Agent Skill for public relations, communication and brand decisions. Describe your situation in ordinary language; the adviser helps turn the facts into a strategy, practical team actions and the messages you need.

**0.6.4-draft.2 — beta candidate, not a stable release.** Chinese and English are the primary working languages. Advice should follow the actual market, available people and budget. The host supplies the model, tools and usage allowance; the Skill has no API key, server, paid service or private research connection.

[Fixed-version installation manifest](install-manifest.json) · [Installation and actual support](INSTALL.md) · [License](LICENSE)

## Current limits

Installation, persistent invocation and professional quality are separate checks. This candidate has not demonstrated overall superiority to ordinary AI. A bounded ChatGPT Work consultation was broadly usable; other tested hosts have produced unsupported policies or inaccurate details. Review facts and commitments before using external-facing text. Do not treat a generic disclaimer as a substitute for checking them.

One-sentence installation is an experience goal, not a compatibility claim. Only methods explicitly marked **verified** in the installation guide have completed that chain. A manual ZIP import does not count as a natural-language install.

## Use

After installation, open a new task and describe your goal, market, current facts and practical limits. You can begin with incomplete information. The adviser should give an initial judgment and useful action, ask only consequential questions, update the plan when facts change, and deliver the strategy, responsibilities, timing and necessary communication materials. You can ask it to continue with stated assumptions if you do not want more questions.

No subscription purchase is required by this project. Host account eligibility and quotas still apply; use an existing allowance and stop at any payment prompt.
