# Project boundaries

Keep this project isolated from unrelated systems. Store raw consultation transcripts and nonpublic
research outside the repository. The V1 Skill must not connect to a private knowledge store.
Use original, publicly shareable examples and clearly scoped source summaries.
Run `python3 -m unittest discover -s tests` and `python3 tools/validate.py` before a development commit.
Do not equate structural checks with professional acceptance. Do not publish or change repository
visibility without the owner's explicit approval.
