# Roadmap

V1 prioritizes installation, natural consultation, feasible operational remedies and bounded
bilingual communication. Improve the small bundled knowledge set using observed user needs and
meaningful comparisons, without making document count a quality metric.

A future V2 may support permission-scoped retrieval from private research. That requires explicit
authorization, isolation between users, source provenance and controls against unintended output.
V1 does not implement a server, online connector or live access to a private store.
