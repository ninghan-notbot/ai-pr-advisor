# AI PR Advisor

面向公关、传播与品牌决策的标准 Agent Skill。用自然语言说明问题，让顾问把事实转化为策略、团队行动和所需沟通材料。

**0.6.4-draft.2：内测候选，不是稳定版。** 中英文为主要工作语言；按实际市场、人员和预算形成建议。模型、工具和额度由宿主提供，本项目不需要 API Key、服务器、付费服务或私有研究库连接。

[固定版本安装清单](install-manifest.json) · [安装方法与实际支持范围](INSTALL.md) · [MIT 许可证](LICENSE)

## 当前限制

安装、持久调用和专业质量分别判断。尚未证明整体优于普通 AI。一次限定场景的 ChatGPT Work 咨询基本可用；其他已测入口出现过无依据政策或细节错误。对外使用前应核对事实与承诺，不能用通用免责声明代替核对。

“一句话安装”是体验目标。仅安装指南明确标注“已验证”的路径算完成；手动导入 ZIP 不等于自然语言安装成功。

## 使用

安装后开启新任务，说明目标、市场、事实及执行限制。信息不完整也可以开始；顾问应先给判断和有用行动，追问关键问题，随事实调整方案，交付策略、分工、节奏及必要文案。不愿继续回答时，可以要求说明假设后继续。

本项目不要求购买订阅；宿主账户资格及额度仍适用。使用已有额度，遇到收费提示应停止。
