# AI 公关顾问

一款可安装的 Agent Skill，帮助用户判断公关问题并落实企业行动。用自然中文或英文描述
客诉、争议主张、服务故障或媒体机会，顾问会澄清核心问题，根据新事实调整判断，逐步形成
与资源相称的传播和执行方案。

面向不同专业水平的全球用户。使用什么语言不等于处于哪个市场；建议应根据实际国家、受众、
行业和资源判断。中英文为重点语言，其他语言及市场的能力仍需逐步验证。

**0.6.1-rc.1 发布候选版。** 安装成功与专业效果分别核验，尚未证明整体优于普通 AI。
公开发布须经用户批准。

## 从 GitHub 安装

有仓库访问权限的用户，可让 Codex 的 Skill 安装器从
[GitHub 链接](https://github.com/ninghan-notbot/ai-pr-advisor/tree/main)安装，仓库内路径为 `.`，
安装名为 `ai-pr-advisor`，使用已授权的下载方式。

GitHub 安装读取所选分支或提交；测试前请核对提交 ID 和 `SKILL.md` 中的版本号。
本份文件说明 **0.6.1-rc.1**。上述授权下载方式曾在已审计的 **0.4.0-rc.2** 基线上实测，
后续提交需分别确认安装结果。仓库为 Private 时需要访问授权。
根目录 Git 稀疏检出方式曾漏掉参考资料子目录，暂不用于此布局。
详见[安装与实际平台状态](docs/compatibility.md)。

也可从已获授权的本地项目安装到一个现有工作目录：

```sh
python3 tools/install.py --project /path/to/your-project --platform codex
```

同一个顾问核心可准备其他宿主的文件布局：Claude Code 使用 `--platform claude`，Kimi Code
使用 `--platform kimi`。布局准备好不等于已实测安装和触发。豆包工作继续作为实际导入与用户
体验的优先验证目标；普通聊天上传提示词或文档不等于安装 Skill。

## 从实际问题开始

“我们的维修预约一直延迟，客户开始失去信心，今天该怎么办？”

随后回答能够确认的问题即可。也可以直接要求方案、提供草案供评估，或说明某些信息暂时
拿不到。支持自动选择 Skill 的宿主可由普通问题触发；否则使用宿主的技能选择器或明确调用。

顾问交付应包括有依据的判断、实际补救、可行的责任与审批安排、适合受众的沟通，以及事实
变化后的修订办法。小团队可能只需要简短行动建议，复杂问题再形成全案。相关参考资料与
当前公开调查按需使用，取决于宿主能力。

## 使用范围与当前状态

不需要也不附带服务器、收费 API 客户端或私有研究库连接。咨询使用您原有大模型账户及工具
权益。建议和草案不会代替您发布信息、联系他人或批准支出。

Codex 已有安装与咨询运行证据。豆包工作、Kimi、Claude Code、ChatGPT、DeepSeek、Muse及其他
宿主，均按真实安装与触发能力评估；文件格式相同不等于全部兼容。
