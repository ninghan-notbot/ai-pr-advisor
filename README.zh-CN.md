# AI 公关顾问

一款可安装的中英文 Agent Skill。直接描述客诉、服务故障、舆情或媒体问题，顾问会根据回答
调整追问，结合企业人数、预算、时间和权限，提出业务补救、责任分工及传播建议。

当前为 **0.4.0-rc.2 候选版**。安装记录、实际调用和专业质量分别评估，具体状态见
[平台说明](docs/compatibility.md)及[测试说明](docs/evaluation.md)。

## 安装与开始

在项目目录运行：

```sh
python3 tools/install.py --project /path/to/your-project --platform codex
```

Claude Code 使用 `--platform claude`，Kimi Code 使用 `--platform kimi`。也可把标准 ZIP
中的完整 `ai-pr-advisor` 文件夹放入平台对应的技能目录。豆包工作保留独立的 ZIP 导入候选包；
不得将普通聊天上传或开发者平台文档支持等同于桌面端实际安装成功。

安装后可以直接说：“我们的社区书店预约取书经常延迟，客人已经在评论区抱怨，今天该怎么办？”
如宿主没有自动选中，请使用它的技能选择器或明确调用技能，再继续正常对话。

40 张知识卡按八类问题按需读取，不把全部内容塞进每轮回答。V1 不连接外部私有案例库。
顾问不会自动联系媒体、发布信息或购买服务；补偿、延保、加人或新增支出仍须有权负责人批准。

Skill 本身不调用付费 API；运行依赖您所选平台及其现有账户权益。原创代码、方法说明和知识
